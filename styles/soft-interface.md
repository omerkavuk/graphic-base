# Soft Interface

> graphic base's own design recipe. References (grammar only): type foundry and library sites (Uncut): a grey ground, one huge display word, rounded pill rows with numbers.

## 1. Essence, and what it is not
- **One display word** with personality (reverse contrast, ink traps, a stencil cut) fills the top.
- **Content as a list of soft rows:** each row a rounded rectangle, a label in capitals, a number in an outlined circle on the right.
- **Toggle details:** small outlined pills (LIST · GRID, SEARCH) as accents.

Not a real app screenshot (no browser chrome, no icons everywhere), not glassmorphism.

## 2. Materials and rendering
- Ground #c4c4c4 to #d9d9d9; rows one step lighter (#d6d6d6) with 12 to 20 px radius.
- Outlined circles and pills, 1.5 px black.

## 3. Colour logic
- Grey, black and white only; one accent if the brand needs it.

## 4. Type
- Display: a striking free face (Bricolage Grotesque at heavy weight, Rubik Mono One, a reverse-contrast or stencil display); rows in a clean grotesque, capitals.

## 5. Pitfalls
- Rows must carry real content (agenda items, figures, categories), never filler.
- Low contrast greys: check text at 4.5:1.

## 6. Variation space
- Formats: programmes and agendas, lists and rankings, product menus, event line-ups, report contents pages.
- Take the grammar (palette logic, type, spacing, structure), never the reference's layout.
